# Security Policy

## Supported Versions

Until the first mainline release of ulb, there are no released versions that receive ongoing security updates.

When a security vulnerability is confirmed and fixed, the fix will be included in the next minor release. For serious vulnerabilities, a release may be made sooner when necessary.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in ulb, please report it through GitHub's [Private Vulnerability Reporting Feature].

Reports submitted privately will be reviewed before any details are made public.

Issues that are determined to have a low security impact may instead be moved to the public issue tracker for further discussion and resolution.

[Private Vulnerability Reporting Feature]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability
